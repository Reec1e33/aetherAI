# AetherAI

This repository is in a full rewrite. The new project will replace this file.

## Version 1

AetherAI v1 was a SpartaHack X hackathon project from February 2025, by Reece Roskam and Tanzil Zubair Bin Zaman. It rewrote a user's query with an LLM and showed the answers to the original and the rewritten query side by side. The v1 code is at the [`spartahack-2025`](https://github.com/Reec1e33/aetherAI/tree/spartahack-2025) tag.

v1 also showed a "time saved" value: the ratio of the two answer lengths, multiplied by 20 seconds. That value did not measure saved time, and it is not valid.
